1 Context-Free Grammars

A context-free grammar (CFG) is a language generator in which a rule can be applied to a nonterminal independently of its context, that is, the surrounding strings. The symbol on the left of a rule is a nonterminal, usually written as an uppercase letter. Terminals, usually written as lowercase letters, do not appear on the left of a rule and mark the end of the generation process.

A CFG is a four-tuple G=(V,Σ,R,S)G = (V, \Sigma, R, S)G=(V,Σ,R,S), where:

  • VVV is an alphabet.

  • Σ⊆V\Sigma \subseteq VΣ⊆V is the set of terminals.

  • R⊆(V−Σ)×V∗R \subseteq (V - \Sigma) \times V^*R⊆(V−Σ)×V∗ is a finite set of rules.

  • S∈V−ΣS \in V - \SigmaS∈V−Σ is the start symbol.

The members of V−ΣV - \SigmaV−Σ are nonterminals. For A∈V−ΣA \in V - \SigmaA∈V−Σ and u∈V∗u \in V^*u∈V∗, write A→GuA \rightarrow_G uA→G​u when (A,u)∈R(A, u) \in R(A,u)∈R.

Write u⇒Gvu \Rightarrow_G vu⇒G​v if and only if there are strings x,y∈V∗x, y \in V^*x,y∈V∗, a nonterminal A∈V−ΣA \in V - \SigmaA∈V−Σ, and a rule A→Gv′A \rightarrow_G v'A→G​v′ such that u=xAyu = xAyu=xAy and v=xv′yv = xv'yv=xv′y. A derivation from w0w_0w0​ to wnw_nwn​ is a sequence w0⇒Gw1⇒G⋯⇒Gwnw_0 \Rightarrow_G w_1 \Rightarrow_G \cdots \Rightarrow_G w_nw0​⇒G​w1​⇒G​⋯⇒G​wn​, where w0,…,wn∈V∗w_0, \dots, w_n \in V^*w0​,…,wn​∈V∗. Its length, or number of steps, is n≥0n \ge 0n≥0.

2 Parse Trees

A parse tree records the structure of a derivation without fixing the order in which independent rules are applied. Its internal nodes are labeled with nonterminals, and its leaves are labeled with terminals or the empty string eee. Its yield is the string obtained by concatenating the leaf labels from left to right.

Parse trees are defined inductively:

  • A single node labeled with a∈Σa \in \Sigmaa∈Σ is a parse tree with root and yield aaa.

  • If (A→e)∈R(A \rightarrow e) \in R(A→e)∈R, a root labeled AAA with one child labeled eee is a parse tree with yield eee.

  • If parse trees have roots A1,…,AnA_1, \dots, A_nA1​,…,An​ and yields y1,…,yny_1, \dots, y_ny1​,…,yn​, and (A→A1⋯An)∈R(A \rightarrow A_1 \cdots A_n) \in R(A→A1​⋯An​)∈R, attaching them in order to a new root AAA gives a parse tree with yield y1⋯yny_1 \cdots y_ny1​⋯yn​.

Only trees obtained by these rules are parse trees.

2.1 Leftmost and Rightmost Derivations

Suppose two derivations DDD and D′D'D′ agree except for two consecutive, independent rule applications. If DDD first replaces a nonterminal to the left and then one to the right, while D′D'D′ performs the same replacements in the opposite order, write D≺D′D \prec D'D≺D′ and say that DDD precedes D′D'D′. In comparing derivations this way, each step records the particular occurrence being replaced.

Two derivations are similar if their pair belongs to the reflexive, symmetric, transitive closure of ≺\prec≺. Equivalently, one can be obtained from the other by switching the order of independent rule applications.

A leftmost derivation always replaces the leftmost nonterminal. Formally, write x⇒Lyx \xRightarrow{L} yxL​y if x=wAβx = wA\betax=wAβ and y=wαβy = w\alpha\betay=wαβ, where w∈Σ∗w \in \Sigma^*w∈Σ∗, α,β∈V∗\alpha, \beta \in V^*α,β∈V∗, and A→αA \rightarrow \alphaA→α is a rule. A rightmost derivation always replaces the rightmost nonterminal; its step relation is denoted by ⇒R\xRightarrow{R}R​.

Theorem. For a CFG G=(V,Σ,R,S)G = (V, \Sigma, R, S)G=(V,Σ,R,S), a nonterminal A∈V−ΣA \in V - \SigmaA∈V−Σ, and a string w∈Σ∗w \in \Sigma^*w∈Σ∗, the following statements are equivalent:

  • A⇒G∗wA \Rightarrow_G^* wA⇒G∗​w.

  • There is a parse tree with root AAA and yield www.

  • There is a leftmost derivation A⇒L∗wA \xRightarrow{L}^{*} wAL​∗w.

  • There is a rightmost derivation A⇒R∗wA \xRightarrow{R}^{*} wAR​∗w.

Proof. Starting from a derivation, begin with a single, temporarily unexpanded node labeled AAA. Whenever a step replaces a particular occurrence of BBB by α\alphaα, attach the symbols of α\alphaα as children of the corresponding frontier node. For an empty-string rule, attach a child labeled eee. The frontier, with empty-string labels omitted, is the current sentential form after every step. At the end, all nonterminals have been expanded, so the result is a parse tree with yield www.

Conversely, given a parse tree, repeatedly expand the leftmost unexpanded nonterminal according to its children in the tree. Each expansion is a grammar rule, and the finite tree eventually has only its terminal leaves on the frontier. This gives a leftmost derivation of www. Expanding the rightmost unexpanded nonterminal instead gives a rightmost derivation. Every leftmost or rightmost derivation is also an unrestricted derivation, completing the equivalence.

Theorem. Every parse tree has exactly one leftmost derivation and exactly one rightmost derivation. Parse trees represent equivalence classes of similar derivations.

Proof. At each stage of a leftmost derivation associated with a fixed tree, both the occurrence to expand and its children are fixed. Hence the next rule application is uniquely determined. Induction on the number of expanded internal nodes proves uniqueness; existence follows from the previous construction. The rightmost case is identical.

For the equivalence-class statement, regard each internal node as one rule application. A valid order of applications must expand every ancestor before its descendants. Applications at incomparable nodes are independent, so switching two consecutive such applications preserves the tree. Conversely, take two valid expansion orders for the same tree. Their first differing application can be moved left to its desired position by swapping it with the intervening applications: none can be its ancestor, since those already occur earlier in both orders, or its descendant, since descendants cannot precede it. Repeating this argument makes the orders identical. Thus precisely the derivations of the same tree are connected by independent switches.

2.2 Ambiguity

A grammar is ambiguous if some string in its language has two or more distinct parse trees. It is unambiguous if every string in its language has exactly one parse tree. By the correspondence above, ambiguity is equivalent to the existence of two distinct leftmost derivations of the same string, and also to the existence of two distinct rightmost derivations.

Ambiguity can sometimes be removed by introducing new nonterminals and constructing an equivalent unambiguous grammar. A context-free language is inherently ambiguous if every CFG generating it is ambiguous.

3 Pushdown Automata

Context-free languages are not necessarily regular, so finite automata do not recognize all CFLs. A pushdown automaton (PDA) adds a stack as auxiliary storage and can be viewed as an NFA equipped with a stack. A stack permits reading and writing only at its top. A push adds a symbol to the top, and a pop removes the top symbol.

A PDA is a six-tuple M=(K,Σ,Γ,s,F,Δ)M = (K, \Sigma, \Gamma, s, F, \Delta)M=(K,Σ,Γ,s,F,Δ), where:

  • KKK is a finite set of states.

  • Σ\SigmaΣ is the input alphabet.

  • Γ\GammaΓ is the stack alphabet.

  • s∈Ks \in Ks∈K is the initial state.

  • F⊆KF \subseteq KF⊆K is the set of final states.

  • Δ\DeltaΔ is a finite subset of (K×(Σ∪{e})×Γ∗)×(K×Γ∗)(K \times (\Sigma \cup \{e\}) \times \Gamma^*) \times (K \times \Gamma^*)(K×(Σ∪{e})×Γ∗)×(K×Γ∗), called the transition relation.

A transition ((p,a,β),(q,γ))∈Δ((p, a, \beta), (q, \gamma)) \in \Delta((p,a,β),(q,γ))∈Δ allows the machine, in state ppp with β\betaβ at the top of the stack, to read aaa, replace β\betaβ by γ\gammaγ, and enter qqq. If a=ea = ea=e, no input is read. More than one transition may be applicable, so this model is nondeterministic.

A configuration is a member of K×Σ∗×Γ∗K \times \Sigma^* \times \Gamma^*K×Σ∗×Γ∗, specifying the current state, the unread input, and the stack contents. The stack is written with its top at the left and its bottom at the right.

Write (p,x,α)⊢M(q,y,ζ)(p, x, \alpha) \vdash_M (q, y, \zeta)(p,x,α)⊢M​(q,y,ζ) if there is a transition ((p,a,β),(q,γ))∈Δ((p, a, \beta), (q, \gamma)) \in \Delta((p,a,β),(q,γ))∈Δ such that x=ayx = ayx=ay, α=βη\alpha = \beta\etaα=βη, and ζ=γη\zeta = \gamma\etaζ=γη for some η∈Γ∗\eta \in \Gamma^*η∈Γ∗. Under the acceptance convention used here, MMM accepts w∈Σ∗w \in \Sigma^*w∈Σ∗ if and only if (s,w,e)⊢M∗(p,e,e)(s, w, e) \vdash_M^* (p, e, e)(s,w,e)⊢M∗​(p,e,e) for some p∈Fp \in Fp∈F. Thus the input must be exhausted, the stack must be empty, and the state must be final.

4 Pushdown Automata and Context-Free Grammars

Theorem. A language is context-free if and only if some PDA accepts it.

The proof has two directions: construct a PDA from a CFG, and construct a CFG from a PDA.

4.1 From a CFG to a PDA

Lemma. Every context-free language is accepted by a PDA.

Proof. Given G=(V,Σ,R,S)G = (V, \Sigma, R, S)G=(V,Σ,R,S), construct M=({p,q},Σ,V,p,{q},Δ)M = (\{p, q\}, \Sigma, V, p, \{q\}, \Delta)M=({p,q},Σ,V,p,{q},Δ). Its transitions are:

  • ((p,e,e),(q,S))((p, e, e), (q, S))((p,e,e),(q,S)).

The first transition puts the start symbol on the stack. Thereafter the PDA either expands the nonterminal on top of the stack or matches and pops a terminal. Because the top is at the left, expansions simulate a leftmost derivation.

To prove that L(M)⊆L(G)L(M) \subseteq L(G)L(M)⊆L(G), fix an input www. For the reverse inclusion, take a leftmost derivation of www, whose existence follows from the parse-tree theorem. Match and pop any terminal prefix on the stack, then simulate the next leftmost grammar rule with the corresponding expansion transition. Repeating this process follows the entire finite derivation. 5 Languages that Are and Are Not Context-Free

5.1 Closure Properties

Theorem. Context-free languages are closed under union, concatenation, and Kleene star.

Proof. Let G1=(V1,Σ,R1,S1)G_1 = (V_1, \Sigma, R_1, S_1)G1​=(V1​,Σ,R1​,S1​) and G2=(V2,Σ,R2,S2)G_2 = (V_2, \Sigma, R_2, S_2)G2​=(V2​,Σ,R2​,S2​). Rename nonterminals so that their nonterminal sets are disjoint, and choose a fresh start symbol SSS.

5.2 Parse-Tree Height and the Pumping Theorem

The fanout ϕ(G)\phi(G)ϕ(G) of a CFG is the largest number of symbols on the right-hand side of a rule. A path in a parse tree consists of distinct nodes joined by successive edges; its length is the number of edges. The height of a rooted parse tree is the length of its longest root-to-leaf path.

Theorem. For a grammar with fanout ϕ(G)≥1\phi(G) \ge 1ϕ(G)≥1, the yield of a parse tree of height hhh has length at most ϕ(G)h\phi(G)^hϕ(G)h.

Proof. Induct on hhh. At height zero, a terminal tree has yield length one, equal to ϕ(G)0\phi(G)^0ϕ(G)0. At positive height, a nonempty production gives at most ϕ(G)\phi(G)ϕ(G) subtrees, each of height at most h−1h - 1h−1. By induction their yields have total length at most ϕ(G)ϕ(G)h−1=ϕ(G)h\phi(G)\phi(G)^{h-1} = \phi(G)^hϕ(G)ϕ(G)h−1=ϕ(G)h. An empty-string production has yield length zero and also satisfies the bound. If all productions have empty right-hand sides, the grammar generates no nonempty strings, so the corresponding nonempty-yield statements are vacuous.

Pumping theorem. For every CFL LLL, there is an integer p≥1p \ge 1p≥1 such that every w∈Lw \in Lw∈L with ∣w∣≥p|w| \ge p∣w∣≥p has a decomposition w=uvxyzw = uvxyzw=uvxyz satisfying:

  • vy≠evy \ne evy=e.

  • ∣vxy∣≤p|vxy| \le p∣vxy∣≤p.

  • uvnxynz∈Luv^nxy^nz \in Luvnxynz∈L for every integer n≥0n \ge 0n≥0.

The upper occurrence is among the last m+1m + 1m+1 nonterminal nodes on a longest path, so its subtree has height at most m+1m + 1m+1. The same argument also gives the grammar-specific form: every string longer than ϕ(G)∣V−Σ∣\phi(G)^{|V - \Sigma|}ϕ(G)∣V−Σ∣ can be pumped with vy≠evy \ne evy=e, without asserting this particular local length bound. The pumping property is necessary but not sufficient for context-freeness. To use it to prove that a language is not context-free, assume a pumping length exists, choose a sufficiently long member, and show that every allowed decomposition fails for some pumping exponent.

5.3 Failure of Intersection and Complement Closure

Theorem. Context-free languages are not closed under intersection or complement.

Proof. First show that E={anbncn:n≥0}E = \{a^n b^n c^n : n \ge 0\}E={anbncn:n≥0} is not context-free. If it had pumping length ppp, take w=apbpcpw = a^p b^p c^pw=apbpcp. In any allowed decomposition w=uvxyzw = uvxyzw=uvxyz, the substring vxyvxyvxy has length at most ppp, so it cannot contain both an aaa and a ccc: doing so would require including the entire block of ppp intervening symbols as well. Thus vvv and yyy together involve at most two symbol types. Pumping down to uxzuxzuxz removes at least one symbol of these types but leaves the count of a third type equal to ppp. The three counts are no longer equal, contradicting the pumping theorem.

Now define

L1={aibicj:i,j≥0},L2={aibjcj:i,j≥0}.L_1 = \{a^i b^i c^j : i, j \ge 0\}, \qquad L_2 = \{a^i b^j c^j : i, j \ge 0\}.L1​={aibicj:i,j≥0},L2​={aibjcj:i,j≥0}.

The grammar rule A→aAb∣eA \rightarrow aAb \mid eA→aAb∣e generates equal blocks of the first two symbols, and B→bBc∣eB \rightarrow bBc \mid eB→bBc∣e generates equal blocks of the last two. Therefore L1L_1L1​ is the concatenation of a CFL with the regular language c∗c^*c∗, and L2L_2L2​ is the concatenation of the regular language a∗a^*a∗ with a CFL. Both are context-free, but L1∩L2=EL_1 \cap L_2 = EL1​∩L2​=E is not. This disproves intersection closure.

If CFLs were closed under complement, their established closure under union and De Morgan's law would imply intersection closure:

L1∩L2=L1‾∪L2‾‾.L_1 \cap L_2 = \overline{\overline{L_1} \cup \overline{L_2}}.L1​∩L2​=L1​​∪L2​​​.

The contradiction proves that complement closure also fails. All complements here are taken relative to the same alphabet.

5.4 Establishing Context-Freeness

To prove that a language is context-free, one can construct a CFG or PDA, show it is finite and hence regular, or apply closure properties. To prove that it is not context-free, one can use the pumping theorem or closure properties. In particular, if its intersection with a regular language is a known non-CFL, the original language cannot be context-free.

There is no algorithm deciding context-freeness for languages given by arbitrary Turing-machine descriptions. This claim concerns general language descriptions; membership in a language already specified by a CFG is decidable, as shown in Section 3.6.

Proof of the undecidability claim. This reduction uses the undecidability of the halting problem. Given a machine MMM and input www, construct a recognizer NNN that, on input xxx, first simulates MMM on www. If that simulation halts, NNN accepts exactly when x∈Ex \in Ex∈E, where EEE is the non-CFL above. If the simulation never halts, NNN never accepts. Thus L(N)=EL(N) = EL(N)=E when MMM halts and L(N)=∅L(N) = \emptysetL(N)=∅ otherwise. A context-freeness decider would distinguish these two cases and decide halting, a contradiction.

6 Algorithms for Context-Free Grammars

6.1 Polynomial-Time Conversions

Theorem. An equivalent PDA can be constructed from a CFG in polynomial time, and an equivalent CFG can be constructed from a PDA in polynomial time.

Proof. The CFG-to-PDA construction in Section 3.4 adds one initialization transition, one expansion transition per grammar rule, and one matching transition per terminal. The total length of the expansion transitions is proportional to the total length of the grammar rules. Its size and construction time are therefore linear in the grammar description.

For the other direction, normalization introduces only polynomially many states and transitions. If the normalized PDA has state set QQQ, stack alphabet Λ\LambdaΛ, and ordinary transition set Δ\DeltaΔ, the CFG uses ∣Q∣2∣Λ∣|Q|^2|\Lambda|∣Q∣2∣Λ∣ triple nonterminals and one start symbol. Each transition generates at most ∣Q∣2|Q|^2∣Q∣2 productions, each of bounded length. Enumerating the nonterminals and productions takes polynomial time, and their correctness was proved in Section 3.4.

6.2 Chomsky Normal Form

A CFG G=(V,Σ,R,S)G = (V, \Sigma, R, S)G=(V,Σ,R,S) is in Chomsky normal form (CNF) if every rule has one of the following forms:

  • S→eS \rightarrow eS→e, present when the language contains the empty string.

  • A→BCA \rightarrow BCA→BC, where A∈V−ΣA \in V - \SigmaA∈V−Σ and B,C∈(V−Σ)−{S}B, C \in (V - \Sigma) - \{S\}B,C∈(V−Σ)−{S}.

  • A→aA \rightarrow aA→a, where A∈V−ΣA \in V - \SigmaA∈V−Σ and a∈Σa \in \Sigmaa∈Σ.

Thus the start symbol never appears on a right-hand side, and only the start symbol may produce the empty string directly. A unit rule has the form A→BA \rightarrow BA→B with both symbols nonterminal. A terminal rule A→aA \rightarrow aA→a is allowed in CNF and is not a unit rule.

Theorem. Every CFG has an equivalent CFG in CNF, constructible in polynomial time. If the start-symbol empty-string rule is omitted, the resulting language is L(G)−{e}L(G) - \{e\}L(G)−{e}.

Proof. We transform the grammar in stages and show that each stage preserves its language.

First introduce a fresh start symbol S0S_0S0​ and the rule S0→SS_0 \rightarrow SS0​→S. The new start symbol has no occurrence on a right-hand side, and its language is unchanged.

Next isolate terminals in right-hand sides of length at least two. For every such terminal aaa, introduce a fresh nonterminal TaT_aTa​ with rule Ta→aT_a \rightarrow aTa​→a, and replace those occurrences of aaa by TaT_aTa​. Expanding or contracting these new one-terminal subtrees establishes language equivalence.

Then replace every long rule A→B1⋯BkA \rightarrow B_1 \cdots B_kA→B1​⋯Bk​, where k≥3k \ge 3k≥3, by a binary chain with fresh nonterminals:

A→B1C1,Ci→Bi+1Ci+1(1≤i≤k−3),Ck−2→Bk−1Bk.\begin{aligned} A &\rightarrow B_1C_1, \\ C_i &\rightarrow B_{i+1}C_{i+1} \quad (1 \le i \le k - 3), \\ C_{k-2} &\rightarrow B_{k-1}B_k. \end{aligned}ACi​Ck−2​​→B1​C1​,→Bi+1​Ci+1​(1≤i≤k−3),→Bk−1​Bk​.​

Each use of the original rule can be expanded into this chain. Conversely, the fresh symbols occur only in their own chain, so the chain can be contracted to the original rule. Every remaining right-hand side now has length at most two.

A nonterminal is nullable, or erasable, if it derives the empty string. Let E={A∈V−Σ:A⇒∗e}\mathcal{E} = \{A \in V - \Sigma : A \Rightarrow^* e\}E={A∈V−Σ:A⇒∗e}. Compute this set by starting with the empty set and repeatedly adding the left-hand side of any rule whose right-hand side consists entirely of already-added nonterminals; an empty right-hand side satisfies this condition immediately.

Every added nonterminal is nullable, by induction on when it is added. Conversely, a parse tree yielding the empty string has only empty-yield subtrees. Induction on its height shows that its root is eventually added. Thus the closure process computes exactly E\mathcal{E}E.

For each binary rule A→BCA \rightarrow BCA→BC, retain it and add A→CA \rightarrow CA→C if B∈EB \in \mathcal{E}B∈E, and A→BA \rightarrow BA→B if C∈EC \in \mathcal{E}C∈E. Remove all empty-string rules, then retain S0→eS_0 \rightarrow eS0​→e exactly when S0∈ES_0 \in \mathcal{E}S0​∈E.

To see that nonempty strings are preserved, take an original parse tree and remove each maximal subtree yielding the empty string. A binary node with one surviving child uses one of the newly added rules. The remaining tree has the same nonempty yield. Conversely, each shortened rule can be expanded by restoring a deleted nullable child and a derivation of its empty yield. The separate start rule preserves the empty string. Binarizing before this step prevents the exponentially many deletion choices that could arise from a single long right-hand side.

Finally eliminate unit rules. For each nonterminal AAA, compute the set U(A)U(A)U(A) of nonterminals reachable from AAA through zero or more unit rules. For every B∈U(A)B \in U(A)B∈U(A) and every non-unit production B→αB \rightarrow \alphaB→α, add A→αA \rightarrow \alphaA→α, then delete all unit rules.

Every new rule simulates a unit-rule chain followed by one non-unit rule. In the reverse direction, contracting every maximal unit-rule chain in a parse tree gives a tree using the new rules. Therefore the language is unchanged. Since S0S_0S0​ never occurs on a right-hand side, no other nonterminal can reach it through unit rules; consequently its empty-string rule is not copied to any other symbol. The remaining productions have exactly the required CNF forms.

Let ggg be the grammar's description size, counting rule symbols. Introducing the start symbol, isolating terminals, and binarizing take linear time and leave a grammar of linear size. Nullable closure requires at most linearly many scans of this grammar. Empty-rule removal adds only constantly many variants per binary rule. Unit reachability can be computed by a graph search from each nonterminal, and copying the reachable non-unit rules creates at most quadratically many rule symbols. These operations admit an O(g2)\mathcal{O}(g^2)O(g2) implementation with unit-cost symbol operations, so in particular the conversion is polynomial.

6.3 Membership Testing by Dynamic Programming

Theorem. Given a CFG GGG and a string xxx, membership x∈L(G)x \in L(G)x∈L(G) can be decided in polynomial time. For a fixed grammar in CNF, the algorithm runs in O(n3)\mathcal{O}(n^3)O(n3) time, where n=∣x∣n = |x|n=∣x∣.

Construction. Convert the grammar to CNF. For a nonempty input x=x1⋯xnx = x_1 \cdots x_nx=x1​⋯xn​, let N[i,j]N[i, j]N[i,j] record the nonterminals generating the substring xi⋯xjx_i \cdots x_jxi​⋯xj​. Initialize the length-one entries by

Fill longer entries in increasing order of substring length. N[i,j]={A∈V−Σ:A⇒G∗xi⋯xj}.N[i, j] = \{A \in V - \Sigma : A \Rightarrow_G^* x_i \cdots x_j\}.N[i,j]={A∈V−Σ:A⇒G∗​xi​⋯xj​}.

For a longer substring, first suppose the algorithm inserts AAA using A→BCA \rightarrow BCA→BC at split kkk. By induction, the children derive their respective substrings, so AAA derives their concatenation. Conversely, any parse tree for a substring of length at least two begins with a binary rule. There are O(n2)\mathcal{O}(n^2)O(n2) table entries and at most O(n)\mathcal{O}(n)O(n) split positions per entry. Scanning the binary rules at each split gives time O(∣R∣n3)\mathcal{O}(|R|n^3)O(∣R∣n3) and space O(∣V−Σ∣n2)\mathcal{O}(|V - \Sigma|n^2)O(∣V−Σ∣n2). For a fixed grammar the time is cubic in the input length. Since CNF conversion is polynomial in the original grammar size, the entire procedure is polynomial in the grammar and input sizes.

6.4 Derivation Length in CNF

Theorem. In CNF, every derivation of a terminal string of length n≥1n \ge 1n≥1 from the start symbol has exactly 2n−12n - 12n−1 steps: n−1n - 1n−1 binary-rule applications and nnn terminal-rule applications.

Proof. The rule S→eS \rightarrow eS→e cannot occur in a derivation of a nonempty string: it would end the derivation immediately, and SSS never appears on a right-hand side. Let bbb be the number of binary-rule applications and ttt the number of terminal-rule applications. Each terminal rule creates exactly one terminal, and terminals are never changed, so t=nt = nt=n. The number of nonterminal occurrences starts at one; each binary rule increases it by one, and each terminal rule decreases it by one. It ends at zero, giving 1+b−t=01 + b - t = 01+b−t=0. Hence b=n−1b = n - 1b=n−1 and the total number of steps is b+t=2n−1b + t = 2n - 1b+t=2n−1.
