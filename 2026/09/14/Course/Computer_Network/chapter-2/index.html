The physical layer interface has the following characteristics:

  • Mechanical characteristics: shape and dimensions, number and arrangement of pins, fixing and locking devices

  • Electrical characteristics: range of signal voltage, impedance matching conditions, transmission rate, distance limitations

  • Functional characteristics: specifies the role of each signal line in the interface cable

  • Procedural characteristics: specifies a set of operational procedures for transmitting a bit stream over the signal lines, including the timing relationships between the signals

1 Transmission Media

Transmission media: the physical path between computer network devices, not included in the computer network architecture (below the physical layer).

1.1 Guided Transmission Media

Coaxial Cable

Categories:

  • Baseband coaxial cable (50 Ω): used for digital transmission, widely used in early local area networks

  • Broadband coaxial cable (75 Ω): used for analog transmission, currently mainly used for cable television drop lines

Coaxial cable is relatively expensive and its cabling is not flexible or convenient enough; with the development of technology and the emergence of hubs, twisted pair is basically used as the transmission medium in the local area network field

Twisted pair

The role of twisting:

  • Reduce electromagnetic interference between adjacent conductors

  • Resist some electromagnetic interference from the outside

Fiber optics

Communication is carried out by using the transmission of light pulses in optical fibers.

Since the frequency of visible light is very high (on the order of about 108 MHz), the transmission bandwidth of an optical fiber communication system is far greater than the bandwidth of various other transmission media currently available.

Classification:

  • Multi-mode fiber

  • Single-mode fiber

1.2 Non-guided transmission medium

  • Microwave

  • Infrared

    • Devices: TV / air conditioner remote controls

    • Infrared communication has been phased out

  • Laser

  • Visible light

2.2 Synchronous transmission and asynchronous transmission

Synchronized transmission

Methods for clock synchronization between the sender and receiver:

  • External synchronization: Add a clock signal line between the sender and receiver.

  • Internal synchronization: The sender encodes the clock signal into the transmitted data and sends them together (e.g., Manchester encoding).

Asynchronous transmission

Asynchronous between bytes, meaning the time interval between bytes is not fixed.

Each bit within a byte still needs to be synchronized, meaning the duration of each bit is the same.

3 Encoding and Modulation

3.1 Basic Concepts

Symbol: When a waveform in the time domain is used to represent a signal, the basic waveform that represents different discrete values.

3.2 Common Encoding Methods

Bipolar Non-Return-to-Zero Encoding (NRZ)

High coding efficiency, but there is a synchronization problem.

How does the receiver determine the symbols?

  • A clock signal line needs to be added for both the sender and receiver.

  • While the sender sends data to the receiver through the data signal line, it also sends a clock signal to the receiver through the clock signal line.

  • The receiver samples the signal on the data signal line according to the rhythm of the received clock signal.

  • For computer networks, it is preferable to use this transmission line to transmit data signals rather than clock signals.

Bipolar return-to-zero encoding

  • At the midpoint of each symbol, the signal returns to zero level.

  • The receiver only needs to sample after the signal returns to zero.

  • Return-to-zero encoding is equivalent to encoding the clock signal into the data using a return-to-zero method, which is called a "self-synchronizing" signal.

  • However, in return-to-zero encoding, most of the data bandwidth is wasted on transmitting the return to zero.

NRZI(not-return-to-zero inverted)

NRZ code that toggles on 1

Principle: At the beginning of each bit, the level toggles on a 1 and does not toggle on a 0.

Manchester encoding

The level transition at the middle of a symbol represents both the clock signal and the data.

Whether a positive transition represents 1 or 0, and a negative transition represents 0 or 1, can be defined as desired.

Problem: The bandwidth overhead is doubled (two symbols represent one bit of data, so the bit rate is only half the baud rate).

Differential Manchester encoding

The level transition at the middle of a symbol represents only the clock signal, not the data.

The representation of data lies in whether there is a level transition at the beginning of each symbol: no transition represents 1, and a transition represents 0.

When transmitting a large number of consecutive 1s or consecutive 0s, the differential Manchester encoded signal has fewer changes than the Manchester encoded signal.

In noisy environments, detecting whether there is a transition is less error-prone than detecting the direction of the transition, so the differential Manchester encoded signal is easier to detect than the Manchester encoded signal.

When incorrect wiring of the transmission medium causes the high and low levels to be reversed, differential Manchester encoding is still effective.

4B/5B Encoding

Ensure sufficient signal transitions so that the receiver stays synchronized and reduces timing errors.

It has higher encoding efficiency compared to Manchester encoding (the encoding method used by Ethernet).

4 The Maximum Capacity of a Channel

4.1 Main Factors Causing Signal Distortion

  1. Symbol transmission rate: The higher the transmission rate, the more severe the distortion of the signal after transmission.

  2. Signal transmission distance: The longer the transmission distance, the more severe the distortion of the signal after transmission.

  3. Noise interference: The greater the noise interference, the more severe the distortion of the signal after transmission.

  4. Quality of the transmission medium: The poorer the quality of the transmission medium, the more severe the distortion of the signal after transmission.

A digital signal transmitted over a channel can be regarded as a square wave formed by the repeated superposition of multiple analog signals of different frequencies.

If the high-frequency components in a digital signal are attenuated during transmission or even cannot pass through the channel, then the leading and trailing edges of the waveform received at the receiving end become less steep, and the time boundary occupied by each symbol is no longer clear. In this way, the signal waveform received at the receiving end loses the clear boundaries between symbols. This phenomenon is called intersymbol interference.

If the frequency band of the channel is wider, then more high-frequency components of the signal can pass through, so the symbol transmission rate can be higher without causing intersymbol interference.

However, the frequency bandwidth of a channel has an upper limit and cannot be infinite, so the symbol transmission rate also has an upper limit.

4.2 Nyquist Theorem

The maximum symbol transmission rate of an ideal low-pass channel = 2W Baud = 2W symbols/second

  • W: the channel's frequency bandwidth (in Hz)

  • Baud: baud, i.e., symbols/second

Using the formula given by the Nyquist theorem, the maximum symbol transmission rate (modulation rate) of the channel can be calculated from the channel's frequency bandwidth.

As long as the symbol transmission rate does not exceed the upper limit calculated according to the Nyquist theorem, intersymbol interference can be avoided.

What the Nyquist theorem gives is the maximum symbol transmission rate of an ideal low-pass channel, which differs considerably from an actual channel; therefore, the maximum symbol transmission rate that an actual channel can transmit is significantly lower than the upper limit given by the Nyquist theorem.

The Nyquist theorem applies to all transmission media.

The relationship between baud rate (symbols) and bit rate (data): when 1 symbol carries only 1 bit of information, the baud rate and the bit rate are numerically equal; when 1 symbol carries n bits of information, when converting the baud rate into the bit rate, the numerical value must be multiplied by n.

The information transmission rate cannot be increased without limit, because there is noise in an actual channel. Noise is randomly generated, and its instantaneous value can sometimes be very large, which affects the receiver's identification of symbols, and the greater the noise power relative to the signal power, the greater the impact.

The ultimate information transmission rate of a channel with limited bandwidth and interference from additive white Gaussian noise is:

The larger the channel's frequency bandwidth WWW or the signal-to-noise ratio S/NS/NS/N in the channel, the higher the channel's ultimate information transmission rate CCC.

An actual channel cannot increase the frequency bandwidth WWW or the signal-to-noise ratio S/NS/NS/N in the channel without limit.

The information transmission rate that can be achieved in an actual channel is considerably lower than the ultimate transmission rate given by the Shannon formula. This is because in an actual channel, the signal is also subject to some other impairments, such as various pulse interferences and signal attenuation, and these factors are not considered in the Shannon formula.

When the channel's frequency bandwidth WWW is fixed, according to the Nyquist theorem and the Shannon formula, in order to increase the information transmission rate, it is necessary to adopt multilevel signaling (more complex modulation techniques) and strive to increase the signal-to-noise ratio in the channel.

Since the publication of the Shannon formula, various new signal processing and modulation methods have continuously appeared, all with the aim of enabling a symbol to carry more bits, and thereby get as close as possible to the transmission rate limit given by the Shannon formula.

5 Channel Multiplexing Technology

5.1 Basic Principles

Multiplexing: transmitting the signals of multiple users simultaneously over a single transmission medium.

When the transmission capacity of a transmission medium is greater than the total transmission capacity of multiple channels, multiplexing technology can be used to establish multiple communication channels on this transmission medium, so as to make full use of the bandwidth of the transmission medium.

Although implementing channel multiplexing increases communication costs (requiring multiplexers, demultiplexers, and a relatively expensive high-capacity shared channel), it is still relatively cost-effective if the number of multiplexed channels is large.

5.2 Common Technologies

Frequency division multiplexing (FDM): all users simultaneously occupy different frequency band resources for parallel communication.

Time division multiplexing (TDM): all users occupy the same frequency band at different times.

Wavelength Division Multiplexing (WDM)

  • Based on the design concept of frequency division multiplexing, multiple optical carrier signals with similar frequencies (wavelengths) can be transmitted simultaneously over a single optical fiber, realizing fiber-based frequency division multiplexing technology.

  • Currently, 80 or more optical carrier signals can be multiplexed over a single optical fiber, so this multiplexing technology is also called Dense Wavelength Division Multiplexing (DWDM).

  • Laying optical cables is extremely costly, so as many optical fibers as possible should be placed in a single optical cable, and then dense wavelength division multiplexing technology should be used for each optical fiber.

Code division multiplexing (CDM)

  • Often called code division multiple access (CDMA), it is a wireless communication technology developed on the basis of spread spectrum communication technology.

  • Each user can communicate using the same frequency band at the same time.

  • Each bit time is divided into m shorter time slices, called chips; the value of m is usually 64 or 128 (for simplicity, the following examples assume that the value of m is 8).

  • In CDMA, each station is assigned a unique m-bit chip sequence: if a station wants to send bit 1, it sends its own m-bit chip sequence; if a station wants to send bit 0, it sends the complement of its own m-bit chip sequence.

  • If two or more stations send data at the same time, the signal in the channel is the superposition of the series of chip sequences or complements of chip sequences sent by these stations.

  • In order to separate each station's signal from the channel, when assigning chip sequences to each station, the following rules must be followed:

    • The chip sequence assigned to each station must be different, and in practice pseudorandom code sequences are often used.

    • The chip sequences assigned to each station must be mutually orthogonal, that is, the normalized inner product between the corresponding chip vectors of each chip sequence is 0.
