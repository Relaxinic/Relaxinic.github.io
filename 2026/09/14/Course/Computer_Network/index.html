Chapter 1 Overview

1.1 Internet

Network: formed by interconnecting several links and nodes.

Internet: formed by interconnecting several networks through routers, a network of networks.

The Internet is the largest internet in the world. The Internet has developed into a multi-level interconnected network based on Internet Service Providers (ISPs).

1.2 Network instance

Network edge

End systems: computers and other devices located at the edge of the Internet and connected to the Internet.

End systems are composed of various hosts: clients (desktop computers, mobile computers, and various other smart terminal devices) and servers.

Functions of hosts: to contain (i.e., run) applications, generate information and send data to the access network, and receive data from the network and provide it to applications.

Access network

  • Goal: to connect hosts to edge routers.

  • Edge routers are the first routers on the path from an end-system host to any other remote end system. Various heterogeneous networks access through edge routers.

  • Connection forms between end systems and edge routers:

    • Wired network access technologies: fiber to the home FTTH, Ethernet, coaxial cable, twisted-pair DSL, and the ancient dial-up Internet access.

    • Wireless network access technologies: WiFi, 4G/5G, and satellite wide-area coverage.

Network core

A mesh network composed of packet-switching devices and communication links of interconnected end systems

Composed of packet switches (routers, link-layer switches) and communication links (fiber optics, copper cables, radio, laser links)

Two major functions:

  • Routing (Global operations): determining the path used by data packets from source to destination. Requires routing protocols and routing algorithms, and produces a routing table.

  • Forwarding (Local operation): a router or switch forwards received data packets onward (i.e., moves them to a certain output interface of the device). Determining the output interface/link to forward to: based on the destination address in the packet header received from the “input interface,” look up the local routing table to determine the “output interface.”

1.3 Circuit switching, packet switching, and message switching

Circuit switching

Data transmission between computers is bursty in nature. When circuit switching is used to transmit computer data, the transmission efficiency of the line is generally very low, and the time actually used on the line to transmit data is often less than 10% or even 1%.

Establish connection (allocate communication resources) - Call (continuously occupy communication resources) - Release connection (return communication resources)

Packet switching

Sender: construct and send packets

Switching nodes: cache and forward packets

Receiver: receive packets and restore the message

Advantages:

  • There is no process of establishing a connection and releasing a connection

  • During packet transmission, communication links are occupied segment by segment, resulting in higher communication line utilization

  • Switching nodes can independently select a forwarding route for each packet, giving the network very good survivability

Disadvantages:

  • The packet header brings additional transmission overhead

  • Store-and-forward processing of packets by switching nodes causes a certain delay

  • It cannot ensure that all end-to-end communication resources are available during communication, and network congestion may occur when traffic is heavy

  • Packets may experience problems such as out-of-order delivery and loss

Message switching

The predecessor of packet switching. The entire message is sent, rather than being split into several packets for transmission. A switching node can only look up the forwarding table after receiving the entire message, and then forward the entire message to the next node. Therefore, compared with packet switching, the forwarding delay is much longer, and the cache space required by the switching node is also much larger.

If a large amount of data needs to be transmitted continuously, and the data transmission time is much greater than the time required to establish a connection, then using circuit switching can achieve relatively high transmission efficiency; however, computer data transmission is often bursty, so when circuit switching is used, the utilization rate of the communication line will be very low.

Neither message switching nor packet switching requires establishing a connection in advance (that is, preallocating communication resources), so when transmitting bursty computer data, they can improve the utilization rate of the communication line.

Dividing a message into several smaller packets for packet switching results in lower delay than performing message switching on the entire message, and it can also avoid an overly long message occupying the link for a long time, which is beneficial to error control and also provides greater flexibility.

1.4 Definition and Classification

A computer network is mainly composed of some general-purpose, programmable hardware interconnected together, and this hardware is not specifically designed to achieve a particular purpose (for example, transmitting data or video signals). This programmable hardware can be used to transmit many different types of data and can support a wide range of and ever-growing applications.

Programmable hardware: not limited to computers, but also includes smart hardware such as smartphones, sensors with network capabilities, and smart home appliances; these hardware devices must contain a CPU.
Various applications: various applications implemented based on data transmission, including various applications that may appear in the future.

Classification:

  • Switching method: circuit / message / packet switching (see the previous section)

  • Users: public network: the Internet; private network: military, railway, electric power, banking

  • Transmission medium: wired network / wireless network

Coverage range:

  • Wide Area Network (WAN): tens to thousands of kilometers

  • Metropolitan Area Network (MAN): 5-50 km

  • Local Area Network (LAN): ~1 km

  • Personal Area Network (PAN): 10 m

Topology: bus / star / ring / mesh

1.5 Performance Metrics

Rate: The transmission rate of data (i.e., how many bits are transmitted per second), also known as data rate or bit rate.

  • The basic unit is bits per second (bit/s, which can be abbreviated as b/s, and is sometimes also written as bps (bit per second)).

  • Commonly used units (note the unit conversions):

    • Kilobits per second (kb/s or kbps) = 10^3 bps

    • Megabits per second (Mb/s or Mbps) = 10^6 bps

    • Gigabits per second (Gb/s or Gbps) = 10^9 bps

    • Terabits per second (Tb/s or Tbps) = 10^12 bps

Bandwidth: refers to the capability of a network’s communication line to transmit data, that is, the maximum data rate that can pass from one point in the network to another per unit time.

  • Unit: same as “rate”

  • Data transmission rate = min[host interface rate, line bandwidth, switch or router interface rate] (short-board effect)

Throughput: the actual amount of data passing through a network or interface per unit time. It is often used to measure an actual network in order to determine exactly how much data has passed through the network. It is limited by network bandwidth.

Delay/latency: the time consumed for data to be transmitted from one end of the network to the other, also called delay or latency.

  • Data may consist of one or more packets, or even a single bit.

  • Transmission latency (also called transmission delay) = packet length (b) / transmission rate (b/s) (for the transmission rate formula, see the “bandwidth” section)

  • Propagation latency = channel length (m) / signal propagation rate (m/s)

  • Queueing latency and processing latency are inconvenient to calculate.

  • Total latency is the sum of the above four latencies.

Bandwidth-delay product = propagation delay * bandwidth, also called the length of the link in bits, which is very helpful for us to understand the minimum frame length of Ethernet later.

Round-trip time (RTT): the total time elapsed from when the sender starts sending a data packet to when the sender receives the corresponding acknowledgment packet sent back by the receiver.

Utilization

  • Link utilization: the percentage of time a link is utilized (that is, data is passing through it); the utilization of a completely idle link is zero.

  • Network utilization: the weighted average of the link utilizations of all links in the network.

  • According to queueing theory, when the utilization of a link increases, the delay caused by that link increases rapidly.

  • When the network traffic is relatively low, the resulting delay is not large, but as network traffic continues to increase, the queueing delay of packets in switching nodes (routers or switches) will increase accordingly, so the delay caused by the network will increase.

  • Let D0D_0D0​ denote the delay when the network is idle, and DDD denote the current delay of the network. Then, under ideal assumptions, the relationship among D,D0D, D_0D,D0​, and network utilization UUU can be expressed by the following formula:

  • Some large ISPs often control channel utilization to no more than 50%; if it exceeds that, they expand capacity by increasing the bandwidth of the line.

Packet loss rate: The ratio of the number of packets lost during transmission to the total number of packets within a certain time range.

  • Divided into interface / node / link / path / network packet loss rate.

  • Packet loss mainly occurs in the following two situations:

    • A packet has a bit error during transmission and is discarded after a node switch (such as a router) or the destination host in the transmission path detects the bit error.

    • A node switch actively discards packets according to a discard policy.

  • The packet loss rate can reflect the congestion situation of the network: when there is no congestion, the path packet loss rate is 0; when there is mild congestion, the path packet loss rate is 1% ~ 4%; when there is severe congestion, the path packet loss rate is 5% ~ 15%.

1.6 Architecture

Two communication modes:

  • Connectionless service: No need to establish a connection in advance

  • Connection-oriented service: Also called virtual circuit service; a virtual circuit must be established before communication

The OSI (open system interconnection) model allows the network layer to support two modes: connectionless (IP) + connection-oriented (X.25 and other protocols)

In the TCP/IP model, the network layer (IP layer) is connectionless, and connection-oriented functionality is implemented by the transport layer (TCP)

Entity: Addresses the problem of implementing specific network applications through the interaction of application processes.

Peer entities: Entities at the same layer on both communicating sides.

Protocol: A set of rules that controls two peer entities in performing “logical communication” in the “horizontal direction.”

  • Three elements of a protocol:

    • Syntax: Defines the format of the information exchanged.

    • Semantics: Defines the operations to be completed by both communicating sides.

    • Synchronization: Defines the timing relationship between both communicating sides.

  • The data packets transmitted between peer layers are called the protocol data unit (PDU) of that layer.

Service:

  • Protocols are “horizontal,” while services are “vertical.”

  • An entity can see the services provided by the lower layer, but does not know the specific protocol that implements the service; the lower-layer protocol is “transparent” to the upper-layer entity.

  • The logical interface through which entities in two adjacent layers in the same system exchange information is called a service access point (SAP), and it is used to distinguish different types of services.

  • The “type” field of a frame, the “protocol” field of an IP datagram, and the “port number” field of a TCP segment or UDP user datagram are all SAPs.

  • For the upper layer to use the services provided by the lower layer, it must exchange some commands with the lower layer, and these commands are called service primitives.

  • The data packets exchanged between layers within the same system are called service data units (SDUs).

  • Six core service primitives (taking connection-oriented services as an example)

2.3 Encoding and Modulation

Basic Concepts

Symbol: When a waveform in the time domain is used to represent a signal, the basic waveform that represents different discrete values.

Common Encoding Methods

Bipolar Non-Return-to-Zero Encoding (NRZ)

High coding efficiency, but there is a synchronization problem.

How does the receiver determine the symbols?

  • A clock signal line needs to be added for both the sender and receiver.

  • While the sender sends data to the receiver through the data signal line, it also sends a clock signal to the receiver through the clock signal line.

  • The receiver samples the signal on the data signal line according to the rhythm of the received clock signal.

  • For computer networks, it is preferable to use this transmission line to transmit data signals rather than clock signals.

Bipolar return-to-zero encoding

  • At the midpoint of each symbol, the signal returns to zero level.

  • The receiver only needs to sample after the signal returns to zero.

  • Return-to-zero encoding is equivalent to encoding the clock signal into the data using a return-to-zero method, which is called a “self-synchronizing” signal.

  • However, in return-to-zero encoding, most of the data bandwidth is wasted on transmitting the return to zero.

NRZI(not-return-to-zero inverted)

NRZ code that toggles on 1

Principle: At the beginning of each bit, the level toggles on a 1 and does not toggle on a 0.

Manchester encoding

The level transition at the middle of a symbol represents both the clock signal and the data.

Whether a positive transition represents 1 or 0, and a negative transition represents 0 or 1, can be defined as desired.

Problem: The bandwidth overhead is doubled (two symbols represent one bit of data, so the bit rate is only half the baud rate).

Differential Manchester encoding

The level transition at the middle of a symbol represents only the clock signal, not the data.

The representation of data lies in whether there is a level transition at the beginning of each symbol: no transition represents 1, and a transition represents 0.

When transmitting a large number of consecutive 1s or consecutive 0s, the differential Manchester encoded signal has fewer changes than the Manchester encoded signal.

In noisy environments, detecting whether there is a transition is less error-prone than detecting the direction of the transition, so the differential Manchester encoded signal is easier to detect than the Manchester encoded signal.

When incorrect wiring of the transmission medium causes the high and low levels to be reversed, differential Manchester encoding is still effective.

4B/5B Encoding

Ensure sufficient signal transitions so that the receiver stays synchronized and reduces timing errors.

It has higher encoding efficiency compared to Manchester encoding (the encoding method used by Ethernet).

2.4 The Maximum Capacity of a Channel

Main Factors Causing Signal Distortion

  1. Symbol transmission rate: The higher the transmission rate, the more severe the distortion of the signal after transmission.

  2. Signal transmission distance: The longer the transmission distance, the more severe the distortion of the signal after transmission.

  3. Noise interference: The greater the noise interference, the more severe the distortion of the signal after transmission.

  4. Quality of the transmission medium: The poorer the quality of the transmission medium, the more severe the distortion of the signal after transmission.

A digital signal transmitted over a channel can be regarded as a square wave formed by the repeated superposition of multiple analog signals of different frequencies.

If the high-frequency components in a digital signal are attenuated during transmission or even cannot pass through the channel, then the leading and trailing edges of the waveform received at the receiving end become less steep, and the time boundary occupied by each symbol is no longer clear. In this way, the signal waveform received at the receiving end loses the clear boundaries between symbols. This phenomenon is called intersymbol interference.

If the frequency band of the channel is wider, then more high-frequency components of the signal can pass through, so the symbol transmission rate can be higher without causing intersymbol interference.

However, the frequency bandwidth of a channel has an upper limit and cannot be infinite, so the symbol transmission rate also has an upper limit.

Nyquist Theorem

The maximum symbol transmission rate of an ideal low-pass channel = 2W Baud = 2W symbols/second

  • W: the channel’s frequency bandwidth (in Hz)

  • Baud: baud, i.e., symbols/second

Using the formula given by the Nyquist theorem, the maximum symbol transmission rate (modulation rate) of the channel can be calculated from the channel’s frequency bandwidth.

As long as the symbol transmission rate does not exceed the upper limit calculated according to the Nyquist theorem, intersymbol interference can be avoided.

What the Nyquist theorem gives is the maximum symbol transmission rate of an ideal low-pass channel, which differs considerably from an actual channel; therefore, the maximum symbol transmission rate that an actual channel can transmit is significantly lower than the upper limit given by the Nyquist theorem.

The Nyquist theorem applies to all transmission media.

The relationship between baud rate (symbols) and bit rate (data): when 1 symbol carries only 1 bit of information, the baud rate and the bit rate are numerically equal; when 1 symbol carries n bits of information, when converting the baud rate into the bit rate, the numerical value must be multiplied by n.

The information transmission rate cannot be increased without limit, because there is noise in an actual channel. Noise is randomly generated, and its instantaneous value can sometimes be very large, which affects the receiver’s identification of symbols, and the greater the noise power relative to the signal power, the greater the impact.

Shannon Formula

The ultimate information transmission rate of a channel with limited bandwidth and interference from additive white Gaussian noise is:

The larger the channel’s frequency bandwidth WWW or the signal-to-noise ratio S/NS/NS/N in the channel, the higher the channel’s ultimate information transmission rate CCC.

An actual channel cannot increase the frequency bandwidth WWW or the signal-to-noise ratio S/NS/NS/N in the channel without limit.

The information transmission rate that can be achieved in an actual channel is considerably lower than the ultimate transmission rate given by the Shannon formula. This is because in an actual channel, the signal is also subject to some other impairments, such as various pulse interferences and signal attenuation, and these factors are not considered in the Shannon formula.

When the channel’s frequency bandwidth WWW is fixed, according to the Nyquist theorem and the Shannon formula, in order to increase the information transmission rate, it is necessary to adopt multilevel signaling (more complex modulation techniques) and strive to increase the signal-to-noise ratio in the channel.

Since the publication of the Shannon formula, various new signal processing and modulation methods have continuously appeared, all with the aim of enabling a symbol to carry more bits, and thereby get as close as possible to the transmission rate limit given by the Shannon formula.

2.5 信道复用技术

基本原理

Multiplexing: transmitting the signals of multiple users simultaneously over a single transmission medium.

When the transmission capacity of a transmission medium is greater than the total transmission capacity of multiple channels, multiplexing technology can be used to establish multiple communication channels on this transmission medium, so as to make full use of the bandwidth of the transmission medium.

Although implementing channel multiplexing increases communication costs (requiring multiplexers, demultiplexers, and a relatively expensive high-capacity shared channel), it is still relatively cost-effective if the number of multiplexed channels is large.

常用技术

Frequency division multiplexing (FDM): all users simultaneously occupy different frequency band resources for parallel communication.

Time division multiplexing (TDM): all users occupy the same frequency band at different times.

Wavelength Division Multiplexing (WDM)

  • Based on the design concept of frequency division multiplexing, multiple optical carrier signals with similar frequencies (wavelengths) can be transmitted simultaneously over a single optical fiber, realizing fiber-based frequency division multiplexing technology.

  • Currently, 80 or more optical carrier signals can be multiplexed over a single optical fiber, so this multiplexing technology is also called Dense Wavelength Division Multiplexing (DWDM).

  • Laying optical cables is extremely costly, so as many optical fibers as possible should be placed in a single optical cable, and then dense wavelength division multiplexing technology should be used for each optical fiber.

Code division multiplexing (CDM)

  • Often called code division multiple access (CDMA), it is a wireless communication technology developed on the basis of spread spectrum communication technology.

  • Each user can communicate using the same frequency band at the same time.

  • Each bit time is divided into m shorter time slices, called chips; the value of m is usually 64 or 128 (for simplicity, the following examples assume that the value of m is 8).

  • In CDMA, each station is assigned a unique m-bit chip sequence: if a station wants to send bit 1, it sends its own m-bit chip sequence; if a station wants to send bit 0, it sends the complement of its own m-bit chip sequence.

  • If two or more stations send data at the same time, the signal in the channel is the superposition of the series of chip sequences or complements of chip sequences sent by these stations.

  • In order to separate each station’s signal from the channel, when assigning chip sequences to each station, the following rules must be followed:

    • The chip sequence assigned to each station must be different, and in practice pseudorandom code sequences are often used.

    • The chip sequences assigned to each station must be mutually orthogonal, that is, the normalized inner product between the corresponding chip vectors of each chip sequence is 0.

Chapter 3 Data link layer

Link: A physical line (wired or wireless) from one node to an adjacent node, with no other switching nodes in between.

Data link: When transmitting data over a link, in addition to the link itself, certain necessary communication protocols are required to control the transmission of this data. Adding the hardware and software that implement these protocols to the link constitutes a data link.

  • The network adapter in a computer (commonly known as a network card) and its corresponding software driver implement these protocols; a typical network adapter includes the functions of both the physical layer and the data link layer.

Frame: The PDU for horizontal logical communication between peer entities at the data link layer.

Services provided by the data link layer

  • Unacknowledged connectionless service: The receiver does not acknowledge the received frames. Applicable scenarios: reliable channels with low bit error rates, real-time communication. Network example: Ethernet.

  • Acknowledged connectionless service: Each frame receives an individual acknowledgment. Applicable scenarios: unreliable channels (wireless channels). Network example: 802.11.

  • Acknowledged connection-oriented service. Applicable scenarios: unreliable channels with long delays.

SDLC / HDLC: Synchronous / High-level Data Link Control

Piggybacking: When the receiver has data to send to the sender, it does not immediately send a pure acknowledgment frame. Instead, it temporarily delays sending the ACK, waiting until the next service data frame is ready to be sent, and then “attaches” the acknowledgment information to the header or a specific field of this data frame and sends it along with it.

3.1 Three questions

Encapsulation into frames and transparent transmission

Encapsulation into frames: The data link layer adds the beginning and end of the frame to the PDU delivered by the upper layer to make it a frame.

  • The beginning and end of the frame contain some important control information.

  • Another function of the beginning of the frame and the end of the frame is frame delimitation, but not every frame of the data link layer protocol contains the frame delimitation mark (such as the MAC frame of Ethernet V2)

  • In order to improve the efficiency of transmission frames, the length of the data load of the frame should be as greater than the length of the first and tail as possible.

  • Considering many factors such as the demand for cache space and error control, each data link layer protocol stipulates the maximum length of the frame’s data load, that is, the maximum transfer unit (MTU)

Transparent transmission: make the data link layer have no restrictions on the content of the PDU delivered by the upper layer, as if the data link layer does not exist.

  • Byte-oriented physical links use the method of byte filling to achieve transparent transmission.

  • Bit-oriented physical links use the method of bit filling to achieve transparent transmission.

Error detection

Frames may have errors during the transmission process.

Bit errors may occur during transmission (called bit errors). Bit 1 may become bit 0, and vice versa.

Over a period of time, the ratio of the number of bits transmitted to the total number of bits transmitted is called the bit error rate (BER)

Increasing the signal-to-noise ratio of the link can reduce the error rate; but in the actual communication link, it is impossible to reduce the error rate to zero.

The receiving party can detect whether there is an error code in the frame according to the error code added by the sender at the end of the frame. The commonly used verification methods are:

Odd-even check

  • Odd check is to add a check bit after the data to be sent, so that the number of bits 1 in the entire data after adding the check bit is odd.

  • Even check is to add a check bit after the data to be sent, so that the number of bits 1 in the whole data after adding the check bit is even.

  • In the transmitted data, if there is an error in the odd bit, the oddity of the number of bits contained in bit 1 will change, and the error code can be detected.

  • In the transmitted data, if there is an error code in an even number of bits, the parity of the number of bits contained in 1 will not change, and the error code cannot be detected (missed detection)

  • In actual use, the parity check can be divided into vertical parity check, horizontal paparity check and horizontal vertical papamity check.

Cyclic redundancy check(cyclic redundancy check, CRC)

This technology with extremely low leakage rate is widely used in the data link layer, because although the calculation is relatively complex, it is very easy to implement with hardware.

The sending and receiving parties agreed to generate a polynomial G(X)G(X)G(X). Based on the data to be sent and G(X)G(X)G(X), the sender calculates the error detection code (redundant code, the length is the maximum number of polynomials generated), and adds the redundant code to the back of the data to be sent and transmits it together.

Redundant code calculation steps:

  1. Construct the divisor: add the maximum number of polynomials to be generated after the data to be sent 0

Two. Construct divisors: generate a bit string composed of coefficients of polynomials as divisors

  1. Do binary module 2 division: equivalent to the logical difference or operation of the corresponding bit

  2. Check the remainder: The number of digits of the remainder should be the same as the maximum number of times to generate a polynomial. If the number of digits is insufficient, add 0 before the remainder to make up the number of digits.

After the recipient receives the data and redundant code, it calculates whether the received data and redundant code have errors through G(X)G(X)G(X)

Specific steps:

  1. Construct the divisor: the received information is used as the divisor

Two. Construct divisors: generate a bit string composed of coefficients of polynomials as divisors

  1. Do binary module 2 division: equivalent to the logical difference or operation of the corresponding bit

  2. Check the remainder: If the remainder is 0, it can be considered that there is no error code in the transmission process; if the remainder is not 0, it can be considered that there is an error code in the transmission process.

Error detection techniques such as parity checks and cyclic redundancy checks can only detect that an error occurred during transmission, but cannot locate the error, and therefore cannot correct it. To correct errors in transmission, error-correcting codes with more redundant information (such as Hamming codes) can be used for forward error correction. However, error-correcting codes have relatively high overhead and are rarely used in computer networks.

In computer networks, the error detection and retransmission methods introduced later are usually used to correct errors in transmission, or frames in which errors are detected are simply discarded, depending on whether the data link layer provides reliable transmission service or unreliable transmission service to its upper layer.

Hamming code

Reliable Transmission

Unreliable transmission service: simply discards frames with bit errors and does nothing else.

Reliable transmission service: ensures that whatever the sender sends can ultimately be correctly received by the receiver.

In general, the bit error rate of wired links is relatively low. Therefore, to reduce overhead, the data link layer is not required to provide reliable transmission service to its upper layers; even if bit errors occur, the problem of reliable transmission is handled by its upper layers.

Wireless links are susceptible to interference and have a relatively high bit error rate. Therefore, the data link layer is required to provide reliable transmission service to its upper layers.

Transmission errors (the first three situations occur in the upper layers of the data link layer, and the last one occurs in the data link layer and its lower layers):

  • Bit errors (bit errors): just introduced above.

  • Packet loss: when the input queue is almost full, received packets are actively discarded.

  • Packet out-of-order: the order in which packets arrive differs from the order in which they were sent.

  • Packet duplication: when a router is busy, packets wait for a long time in the input queue, causing the sender to time out and retransmit, so that the receiver ultimately receives multiple identical packets.

Reliable transmission service is not limited to the data link layer; all other layers may also choose to implement reliable transmission.

The implementation of reliable transmission is relatively complex and has relatively high overhead. Whether to use reliable transmission depends on application requirements.

Stop-and-wait protocol:

If the receiver does not receive the data packet, it will not send the corresponding ACK or NAK. If no measures are taken, the sender will remain in the state of waiting for the receiver’s ACK or NAK.

To solve the above problem, the sender can start a timeout timer each time it finishes sending a data packet.

If the retransmission time-out (RTO) set by the timeout timer is reached but the sender still has not received the receiver’s ACK or NAK, it retransmits the data packet that was previously sent. Generally, the RTO can be set slightly larger than the average round-trip time RTT between the sender and receiver.

To avoid the transmission error of duplicate packets, each packet must carry a sequence number. For the stop-and-wait protocol, since the sender stops and waits after sending each data packet, it is enough to ensure that each time a new data packet is sent, its sequence number is different from that of the previously sent data packet. Therefore, one bit is enough for numbering (0/1).

If the receiver receives a duplicate data packet, it discards it and sends another acknowledgment packet. The acknowledgment packet also needs to be numbered to prevent the sender from mistaking which data packet the acknowledgment packet corresponds to. The number of bits used is the same as the number of bits used for the data packet.

After using the timeout retransmission mechanism, the negative acknowledgment mechanism can be omitted, which makes the protocol simpler to implement. However, if the bit error rate of the point-to-point link is relatively high, using the negative acknowledgment mechanism can enable the sender to retransmit as soon as possible before the timeout timer expires.

The stop-and-wait protocol belongs to the automatic repeat request (ARQ) protocol, that is, the retransmission request is automatically made by the sender, rather than the receiver requesting the sender to retransmit a certain erroneous data packet.

Channel utilization:

  • If timeout retransmission occurs, the channel utilization rate will be even lower for transmitting useful data information.

  • When the RTT is relatively large, in order to improve channel utilization, the sender and receiver are not suitable for using the stop-and-wait protocol, and instead can choose to use the Go-Back-N (GBN) protocol or the Selective Repeat (SR) protocol.

Go-Back-N Protocol (GBN)

Using pipelined transmission can significantly improve channel utilization.

At this time, the sender cannot continuously send data packets without limit; otherwise, routers in the network or the receiver may not have enough time to process these data packets, which may lead to the loss of data packets. This is actually a waste of network resources.

Therefore, in addition to using pipelined transmission, the Go-Back-N protocol also uses a sending window to limit the number of data packets the sender can continuously send. This belongs to the continuous ARQ protocol.

nnn bits are used to number the packets, and the sequence number range is 0∼(2n−1)0 \sim (2^n - 1)0∼(2n−1) (in this example, it is assumed that 3 bits are used to number the packets).

The sender needs to maintain a sending window WTW_TWT​ (range 1<WT≤(2n−1)1 < W_T \le (2^n - 1)1<WT​≤(2n−1)). Without receiving an acknowledgment packet from the receiver, the sender can continuously send all data packets whose sequence numbers fall within WTW_TWT​ (below, take WT=5W_T = 5WT​=5).

The receiver needs to maintain a receiving window WRW_RWR​. Only data packets that arrive correctly at the receiver (without errors) and whose sequence numbers fall within WRW_RWR​ are received by the receiver; the value of WRW_RWR​ can only be 1, which is the same as the stop-and-wait protocol.

Each time the receiver correctly receives a data packet whose sequence number falls within the receiving window, it slides the receiving window forward by one position, so that a new sequence number falls within the receiving window; at the same time, the receiver also needs to send an acknowledgment packet for that data packet to the sender.

Each time the sender receives an acknowledgment packet that is acknowledged in order, it slides the sending window forward by one position, so that a new sequence number falls within the sending window, and data packets whose sequence numbers fall within the sending window can continue to be sent.

During the operation of the Go-Back-N protocol, the sender’s sending window and the receiver’s receiving window continuously slide forward according to the above rules (because this type of protocol is also called a sliding window protocol).

In the absence of transmission errors, the channel utilization of the Go-Back-N protocol is significantly higher than that of the Stop-and-Wait protocol; the degree of improvement depends on the size of the sending window.

An error in one data packet may cause the retransmission of a large number of data packets. When the channel quality is poor (error-prone), the channel utilization of the Go-Back-N protocol is not higher than that of the Stop-and-Wait protocol.

The receiver uses cumulative acknowledgment: the receiver does not have to send an acknowledgment packet for every data packet it receives; instead, after receiving several data packets with consecutive sequence numbers, it can send an acknowledgment packet for the last data packet that arrived in order. When the receiver sends a cumulative acknowledgment packet is determined by the specific implementation. An acknowledgment packet ACKn indicates that all data packets with sequence number n and before have been correctly received.

Advantages:

  • Reduces the number of acknowledgment packets injected into the network

  • Even if an acknowledgment packet is lost, it may not be necessary to retransmit the data packet

Disadvantage: It cannot promptly and accurately reflect to the sender the number of all data packets that the receiver has correctly received.

Ensure that after the receive window slides forward, the new sequence numbers falling within the receive window do not overlap with the previous old sequence numbers, so as to avoid being unable to distinguish between old and new data packets.

Sender:

  • It can send all multiple data packets whose sequence numbers fall within the send window even without having received acknowledgment packets from the receiver.

  • Only when acknowledgment packets for the sent data packets are received in order can the send window slide forward to the corresponding position.

  • If acknowledgment packets that arrive out of order are received, they should be recorded to prevent timeout retransmission of their corresponding data packets, but the send window cannot slide forward.

Receiver:

  • It can receive data packets that arrive out of order but have no bit errors and whose sequence numbers fall within the receive window.

  • In order to make the sender retransmit only the packets in which errors occurred, the receiver no longer uses cumulative acknowledgment, but instead needs to acknowledge each correctly received data packet one by one.

  • Only after receiving data packets in order can the receive window slide forward to the corresponding position.
